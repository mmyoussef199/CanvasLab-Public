# CanvasLab v0.1.0-beta.1

First public beta release.

## Included
- Pixel-accurate HEX, RGB and alpha color picking and representative color palette.
- JPEG, PNG and WebP image loading, resizing and export.
- Actual encoded preview, quality controls for JPEG/WebP, transparency handling and safe original-file preservation.
- Offline Windows desktop experience with no account or image upload.

## Compatibility
- Windows 10/11 x64.
- Self-contained per-user installer; no separate .NET runtime required.
- External testers reported successful installation and operation on Windows 10 and Windows 11.

## Important
- This is a beta. Please report issues through the repository issue tracker.
- The Windows installer is **not digitally signed**. Windows might show an Unknown Publisher or SmartScreen warning. Only obtain the installer from the official release page.
- Installation and use are at the user's own discretion. Do not ignore antivirus detections.
